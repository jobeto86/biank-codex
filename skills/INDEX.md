# Skills auxiliares de Biank

El core distribuye únicamente estas tres skills. Cárgalas cuando corresponda;
no son un catálogo de operaciones de la empresa.

| Skill | Cuándo usarla | Qué hace |
|---|---|---|
| `conectar-cbsuite` | Faltan herramientas, sesión vencida o acceso rechazado | Verifica catálogo, perfil, membresías y tenant; guía OAuth nativo sin copiar credenciales. |
| `actualizarme` | «Actualízate», «¿hay una versión nueva?» | Consulta o aplica una release verificada de GitHub y conserva contenido local. |
| `diagnostico` | «Algo no funciona», instalación incompleta o error repetido | Comprueba el core y las conexiones con evidencia, sin alterar el ERP. |

Las operaciones se descubren y ejecutan con las herramientas MCP autorizadas y
sus firmas vigentes. Usa el descubrimiento del servidor antes de afirmar que falta
una capacidad. Consulta los procesos de la empresa por MCP/wiki del tenant cuando
hagan falta; la wiki no sustituye contratos, permisos ni confirmaciones de herramientas.

El backlog y la memoria breve siguen las instrucciones de `identity/BIANK.md`.
La bienvenida y la revisión de pendientes no requieren skills separadas.

Una carpeta actualizada puede conservar skills o protocolos del core anterior.
No los cargues ni ejecutes como recetas genéricas: este índice es el vigente.
Los archivos y personalizaciones locales se conservan sin borrados automáticos.
